## flashcards

> 线下计分小测，共2题。

- A study was conducted to investigate the effect of a new medication on systolic blood pressure. Blood pressure was measured for 8 patients before and after taking the medication:
    | Participant | Pre-Treatment BP (mmHg) | Post-Treatment BP (mmHg) |
    | ----------- | ----------------------: | -----------------------: |
    | 1           |                     140 |                      150 |
    | 2           |                     150 |                      142 |
    | 3           |                     135 |                      128 |
    | 4           |                     160 |                      180 |
    | 5           |                     145 |                      138 |
    | 6           |                     155 |                      148 |
    | 7           |                     148 |                      170 |
    | 8           |                     142 |                      135 |

    Please determine if the medication has a significant effect on changing blood pressure at alpha = 0.01.

  - 采用配对样本 t 检验，差值 Post-Pre 为 10,-8,-7,20,-7,-7,22,-7，均值 2，样本标准差约 13.16，标准误约 4.65，t=0.43，df=7；双尾 alpha=0.01 时临界值约 3.499，|t|<临界值，不拒绝 H0，尚不能认为该药物对改变血压有显著影响。

- Suppose you want to test whether smoking status is associated with lung disease in a sample of 200 individuals. 
    |            | Lung Disease | No Disease | Total |
    | ---------- | -----------: | ---------: | ----: |
    | Smoker     |           65 |         40 |   105 |
    | Non-smoker |           25 |         75 |   100 |
    | Total      |           90 |        115 |   205 |
    
    Please fill the following table with expected frequencies and perform a Chi-square test at alpha = 0.01 (keep two-decimals during your calculation).
    |            | Lung Disease | No Disease |
    | ---------- | ------------ | ---------- |
    | Smoker     |              |            |
    | Non-smoker |              |            |
  - 期望频数：Smoker-Lung Disease=46.10，Smoker-No Disease=58.90，Non-smoker-Lung Disease=43.90，Non-smoker-No Disease=56.10；卡方统计量约 28.33，df=1，alpha=0.01 时临界值约 6.635，拒绝 H0，可认为吸烟状态与肺病存在关联。
