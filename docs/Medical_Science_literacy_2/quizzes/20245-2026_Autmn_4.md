## flashcards

> 线下计分小测，共2题。

- A study was conducted to investigate the effect of a new medication on systolic blood pressure. Blood pressure was measured for 8 patients before and after taking the medication:
    
    | Participant | Pre-Treatment BP (mmHg) | Post-Treatment BP (mmHg) |
    | ----------- | ----------------------: | -----------------------: |
    | 1           |                     140 |                      130 |
    | 2           |                     150 |                      142 |
    | 3           |                     135 |                      128 |
    | 4           |                     160 |                      152 |
    | 5           |                     145 |                      138 |
    | 6           |                     155 |                      148 |
    | 7           |                     148 |                      142 |
    | 8           |                     142 |                      135 |

    Please determine if the medication has a significant effect on reducing blood pressure at alpha = 0.05.

  - 采用配对样本 t 检验，差值 Pre-Post 为 10,8,7,8,7,7,6,7，均值 7.5，样本标准差约 1.195，标准误约 0.423，t≈17.75，df=7；单尾 alpha=0.05 时临界值约 1.895，t>临界值，拒绝 H0，可认为该药物显著降低收缩压。

- Suppose you want to test whether smoking status is associated with lung disease in a sample of 200 individuals. 
    |            | Lung Disease | No Disease | Total |
    | ---------- | -----------: | ---------: | ----: |
    | Smoker     |           60 |         40 |   100 |
    | Non-smoker |           30 |         70 |   100 |
    | Total      |           90 |        110 |   200 |
    Please fill the following table with expected frequencies and perform a Chi-square test at alpha = 0.05 (keep two decimals during your calculation).
    |            | Lung Disease | No Disease |
    | ---------- | ------------ | ---------- |
    | Smoker     |              |            |
    | Non-smoker |              |            |
  - 期望频数：Smoker-Lung Disease=45.00，Smoker-No Disease=55.00，Non-smoker-Lung Disease=45.00，Non-smoker-No Disease=55.00；卡方统计量约 18.18，df=1，alpha=0.05 时临界值约 3.841，拒绝 H0，可认为吸烟状态与肺病存在关联。
